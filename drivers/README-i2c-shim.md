# BCM2835/7 I2C (BSC1) Driver — FreeBSD KOBJ Shim

## Overview

Ports the **unmodified** FreeBSD `bcm2835_bsc.c` driver to Unikraft/RPi3 via
the same KOBJ shim infrastructure used by the GPIO driver.  No edits to the
FreeBSD source are required.

The FreeBSD driver is used for **hardware initialisation only** (`bcm_bsc_probe`
+ `bcm_bsc_attach` reset the controller and set the 100 kHz clock divider).
Actual I2C transfers use a **direct-MMIO polled** implementation in
`bcm_bsc_shim.c` that bypasses `bcm_bsc_transfer()` entirely, avoiding the
interrupt-driven `mtx_sleep` / `wakeup` dependency.

## Architecture

```
  ┌───────────────────────────────────────────────┐
  │  Application  (measurements/i2c-shim/main.c)  │
  └───────────────────┬───────────────────────────┘
                      │  uk_i2c_init / uk_i2c_write / uk_i2c_read /
                      │  uk_i2c_write_read
  ┌───────────────────▼───────────────────────────┐
  │  drivers/bcm_bsc_shim.c   (Unikraft API)       │
  │  drivers/bsc_kobj_descriptors.c (KOBJ tables)  │
  └──────┬──────────────────────┬─────────────────┘
         │ DEVICE_PROBE/ATTACH  │  direct MMIO (BSC1 @ 0x3F804000)
  ┌──────▼──────────────┐       │
  │ bcm2835_bsc.c        │       │  uk_i2c_write/read bypass
  │ (unmodified FreeBSD) │       │  bcm_bsc_transfer entirely
  └──────────────────────┘       │
                      ┌──────────▼──────────────┐
                      │  BCM2837 BSC1 hardware   │
                      │  GPIO 2 = SDA (pin 3)    │
                      │  GPIO 3 = SCL (pin 5)    │
                      └──────────────────────────┘
```

Key bridging header shared with the GPIO shim: **`drivers/include/bcm_gpio_internal.h`**

## Why Transfer is Bypassed

`bcm_bsc_transfer()` is interrupt-driven: it calls `mtx_sleep()` waiting for
`bcm_bsc_intr()` to set `BCM_I2C_DONE`.  The BSC1 IRQ (GPU IRQ 53) is not
registered in the Unikraft raspi IRQ table, so `bus_setup_intr` is a no-op and
the interrupt never fires.  The polled implementation in `bcm_bsc_shim.c`
replicates the same MMIO register sequence but spins on the STATUS register
instead of sleeping.

## Repeated-START Workaround

The BCM2837 BSC has a silicon bug where a repeated-START cannot be generated by
simply issuing a second START command.  `uk_i2c_write_read()` implements the
documented workaround (also used in `bcm_bsc_transfer`):

1. Start the write with an **empty FIFO** (keeps `xfer_count > 0`).
2. Wait for `TA` (Transfer Active) to confirm the hardware latched DLEN/direction.
3. Pre-set `DLEN = rlen` and `CTRL = I2CEN | ST | READ` while the write is active.
4. Fill the TX FIFO with write data — hardware issues a repeated-START when write ends.
5. Poll `RXD` to drain the FIFO and `DONE` for completion.

## DRIVER_MODULE vs EARLY_DRIVER_MODULE

The GPIO driver uses `EARLY_DRIVER_MODULE` which directly writes `shim_gpio_driver_reg`
in its constructor.  The BSC driver uses `DRIVER_MODULE` (standard, non-early).
The shim redefines `DRIVER_MODULE` as a constructor that calls `_shim_bsc_register()`.
Two constructors fire (one per `DRIVER_MODULE` call); only the one with
`driver.methods != NULL` (`bcm_bsc_driver`) gets registered — `iicbus_driver`
is stubbed with `methods = NULL` and is silently skipped.

## Public API (`<uk/i2c.h>`)

```c
int uk_i2c_init(void);
int uk_i2c_write(uint8_t addr7, const uint8_t *buf, uint16_t len);
int uk_i2c_read(uint8_t addr7, uint8_t *buf, uint16_t len);
int uk_i2c_write_read(uint8_t addr7,
                      const uint8_t *wbuf, uint16_t wlen,
                      uint8_t *rbuf,       uint16_t rlen);
```

Returns 0 on success, `-EIO` on NACK, `-ETIMEDOUT` on timeout.
`addr7` is the 7-bit slave address (not shifted).

## Hardware

```
SDA  →  GPIO 2  (header pin 3)
SCL  →  GPIO 3  (header pin 5)
GND  →  pin 6
3.3V →  pin 1  (for pull-up resistors)
```

Pull-ups: 4.7 kΩ to 3.3 V on each line (many breakout boards include these).

GPIO 2 and 3 must be set to ALT0 before `uk_i2c_init()`:

```c
uk_gpio_init();
uk_gpio_set_func(2, UK_GPIO_FUNC_ALT0);  /* SDA */
uk_gpio_set_func(3, UK_GPIO_FUNC_ALT0);  /* SCL */
uk_i2c_init();
```
